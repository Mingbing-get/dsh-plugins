# 任务描述目录

本目录定义「任务自动分解与排期执行插件」（`task/`）的任务描述文档约定，并可作为运行时产物位置的参照。

约定：

- 文件名格式为 `<task-id>-<slug>.md`，例如 `T1-task-store-schema.md`。
- `<task-id>` 与数据库 `task.id` 一一对应，编号一经分配永不复用。
- 每个可执行任务同时拥有：本目录下的一份文档 + 数据库中的一条任务记录。
- 任务状态以数据库为准，文档中的状态行由插件在执行过程中同步更新。

与运行时产物的区别：插件实际运行时，任务文档生成到被使用的**项目仓库**的 `docs/tasks/` 下，
与本文档所在位置无关；本目录只维护格式与命名约定。

目录内容由插件在任务拆解阶段自动生成，请勿手工新增任务文档（手工新增不会进入调度队列）。
